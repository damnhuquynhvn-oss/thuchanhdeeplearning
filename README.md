# ThucHanhDeepLearning

Giới thiệu
Repository này lưu trữ các bài thực hành và bài tập của môn Thực Hành Deep Learning. Nội dung bao gồm các kiến thức nền tảng về xử lý dữ liệu, TensorFlow, mạng nơ-ron nhân tạo (ANN), học máy và học sâu thông qua các bài lab được thực hiện bằng Python và Jupyter Notebook.

Lab 01 - NumPy & Pandas
Nội dung:
Tạo và thao tác mảng NumPy.
Xử lý dữ liệu bằng Pandas.
Thống kê dữ liệu.
Làm sạch dữ liệu cơ bản.

Lab 01 - TensorFlow
Nội dung:
Cài đặt và sử dụng TensorFlow.
Xây dựng mô hình Sequential.
Huấn luyện mô hình học sâu đơn giản.
Đánh giá độ chính xác mô hình.

Lab 02
Nội dung:
Tiền xử lý dữ liệu.
Chia tập train/test.
Xây dựng mô hình ANN.
Huấn luyện và đánh giá mô hình.
Trực quan hóa kết quả bằng Matplotlib.

Lab 03 - Phần 1
Nội dung:
Xây dựng mô hình phân loại dữ liệu.
Sử dụng TensorFlow/Keras.
Đánh giá hiệu năng mô hình.
Làm việc với các tập dữ liệu mẫu.

Lab 03 - Phần 2
Nội dung:
Mạng tích chập (CNN).
Xử lý dữ liệu ảnh.
Huấn luyện mô hình trên tập dữ liệu ảnh như MNIST/CIFAR.
Đánh giá độ chính xác và khả năng nhận dạng.

Lab 04
Nội dung:
Phân loại ảnh bằng Deep Learning.
Sử dụng dữ liệu MNIST.
Xây dựng và huấn luyện mô hình.
Đánh giá kết quả dự đoán.
